# Observable-digest cost evidence — ms-iri

Accepted implementation from planning main
`6ff6667d098488c00a296f81b3a778da22067a14`, product baseline `bc9a88d`.
P4/E4/O4 and all canonical semantics remain unchanged. The evidence quantifies
actual native work and bytes; it does not measure product throughput or rank CPU
bottlenecks. Independent coordinator acceptance reproduced the evidence and
required checks without a code, contract or scope correction.

At history 1000, one genuine Periodic-to-Toggle owner requires 1,160,381 raw O4
hash bytes and four require 2,115,164, while raw E4 uses 1,541 and 2,297 bytes.
The quiet edge controls remain at 2,493/5,964 O4 bytes and 937/1,744 E4 bytes.
Genuine current ancestry remains complete. Current width and history are separate
dimensions. Warm work also includes growing catalogue/membership/closure work;
the measurements do not establish that O hashing dominates it.

## Boundary and method

Three new private finite tests cover twelve primary cells, eight old-artifact
contrasts and two episode states: 22 real raw E/O build/hash pairs, 34 warm
ordinary publications, four complete snapshots, four owned explanations and
eight lifetime observations. A fourth new test detects reference-accounting
contamination. All new fields have positive real-boundary witnesses and cached
getter default-zero controls. No benchmark dependency, public counter API,
production optimization, new projection or normative amendment was introduced.

Raw E/O call the actual production input builders and BLAKE3 sites. Hash-byte
counters use the exact final input Vec length, including the canonical CBOR
domain/payload/version framing. Provenance payload bytes are a separate sum.
Index entries count physical positions per machine/episode view. Closure roots,
pops and predecessor entries count their actual loops, while visits count first
ordinals per view. Content insertion attempts divide into new canonical content
and equal-content coalescing; output records count only the reachable union.

Fixed keys, domain and policy are used. Quiet edges have independent keyed owners
sharing a Low level input; they receive real ordinary ready reactions. Genuine
Toggle owners share a High-enabled Periodic source with period one and one
chronological advance to the requested history. Hidden owners have no external
outputs. One independent Pulse passthrough supplies the controlled small result.
Warm target is history + 1, with every real deadline/target occurrence preserved.
All warm cells process one reaction and charge their listed topology operation
count. No elapsed-time gate or incidental tree/traversal golden is imposed.

Setup, base duplication and reference/oracle reads are outside captured intervals.
Ordinary apply's private successor clone, admission, freezing, collection,
publication and result selection remain inside. The equivalent predecessor base
is held uniformly during warm calls, so those intervals do not characterize
unobserved predecessor reclamation or complete allocator costs. The separate
held/dropped controls use real prefix artifacts and an independently owned
current machine; they do not retain an old whole-machine view.

The built-in canonical assertion previously suppressed projection_work but still
charged its actual O builder to causal_work. The new regression first failed with
three closure visits/emissions and 545 payload bytes charged by a pure oracle.
Both causal projection hooks now honor the same test-only accounting guard;
the corrected regression passes. This changes accounting, not product behavior.
No other existing counter definition or reference semantics was changed.

## Scope and recommendation

Thirteen unchanged reviewed contracts remain the accepted basis: 65 selected
rule IDs, 516 unchanged citations, no adverse source status. No discovered fact
requires a draft contract, normative amendment or material expansion. The only
code changes are cfg(test) hash/traversal/coalescing accounting and its guard,
the private measurement module and strengthened existing warm rollback test.
Specs/contracts/goldens, Cargo/dependencies, grammar/profile/schema/domain/API,
policy, Makefile, host and exported beads remain excluded from this proposal.

The current O4 contract requires the observed canonical backward-closure payloads.
The packet distinguishes required payload/hash burden from current physical
indexing/coalescing/membership costs and other transaction/artifact work. Fixed
direct-lookup counts do not establish constant lookup CPU cost; byte counts do
not establish frame-time impact, and unlike counters do not yield a bottleneck
percentage. Runner duration includes fixtures and oracles in debug/test builds.

Keep O4 as implemented for this acceptance. A maintainer can use these actual
growth/width numbers with a concrete workload or latency need to separately
prepare an O4-preserving private improvement or review a different semantic
projection. Root hashes alone would be a product projection decision requiring
separate acceptance; these measurements approve none of those actions. No O5,
root-only draft, cap/checkpoint/shim/freeze, historical reopening, retired roadmap,
host adoption or push is selected. This packet completes the bounded measurement
delivery; any later optimization or projection change requires its own reviewed
task.
